# PaperMind-RAG

PaperMind is a research-focused RAG system for analyzing academic papers, generating citation-grounded answers, comparing multiple studies, and identifying research gaps.

Unlike a basic PDF chatbot, PaperMind is designed as a research workflow assistant.

## Planned Features

- Multi-paper PDF upload
- Section-aware PDF parsing
- Citation-grounded question answering
- Paper Card generation
- Multi-paper comparison matrix
- Research gap finder
- Reviewer mode
- Reproducibility checklist
- RAG evaluation dashboard
- Streamlit demo
- FastAPI backend
